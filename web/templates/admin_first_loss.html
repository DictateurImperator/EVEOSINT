Did the character return after their first known loss? Which loss profiles are associated with return, and what changed afterwards?

All identified characters with a loss are included, including first losses against NPCs. Return means subsequent activity in recorded killmails, including NPC losses; login retention is unavailable. PvP return includes participation as attacker or victim against players. The first 30 minutes belong to the initial episode. Missing archives and insufficient follow-up stay unknown.

Profile grouping · Model comparison

Auto tests 2–30 groups with three starts. Among candidates with stability ARI ≥ 0.80, it chooses the smallest count within 0.01 of the best mean silhouette. If none reach that stability, it uses the same rule over valid candidates and flags the choice. Scores describe the grouping of initial losses; return outcomes are excluded from selection.

GroupsMean silhouette · ± start deviationPilot stability · ARISmallest fitting groupSelection

Diagnostic subsets are drawn randomly from the whole population and have bounded size. The chosen count is then fitted using all characters. A weak score or unstable grouping does not establish distinct natural player types.

Which factors are associated with return?

Adjusted probability differences compare an age or ship category with the stated reference while keeping the other initial-loss variables and loss year fixed. Positive values mean more observed return; negative values mean less. Intervals crossing zero are marked uncertain. These are estimated associations with recorded activity.

How much does each factor help predict return?

Importance measures how much prediction deteriorates when a factor is shuffled within the loss year. Shares sum to 100% of positive predictive importance, provided the model converged and beats the year-only baseline. Importance includes missing data indicators: age includes birth-date availability. Correlated factors can share information; a small importance is not proof of no association.

PCA dimensions and explained variance

The cohort selector shows an independently fitted yearly PCA for diagnostics; PC1 in one yearly PCA is not the same direction as PC1 in another. Explained variance describes differences between initial profiles, not the percentage of return explained.
