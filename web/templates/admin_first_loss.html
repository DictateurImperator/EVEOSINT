First loss · Return and trajectories

Did the character return after their first known loss? Which loss profiles are associated with return, and what changed afterwards?

All identified characters with a loss are included, including first losses against NPCs. Return means subsequent activity in recorded killmails, including NPC losses; login retention is unavailable. PvP return includes participation as attacker or victim against players. The first 30 minutes belong to the initial episode. Missing archives and insufficient follow-up stay unknown.
