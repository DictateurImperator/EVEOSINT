Blocked IP addresses

Blocked IP addresses and their blocking reasons are kept indefinitely while blocked. There is no automatic expiry or purge of active blocks. Only an administrator can lift a block. The 30-day cleanup applies only to security records without an active block.

IPReasonAction

30 days of daily metrics and unique visitor counts; the last 1,000 requests are retained. Unique visitor counts use daily HMAC IP pseudonyms, independent of cookies or browser. Shared IPs count once. Older cookie-based unique counts are not mixed with these counts. Raw IPs associated with detected abuse are stored separately for security; account identities, search strings, cookies and public group links are not stored in traffic statistics. Requested paths and fixed client-family labels are retained with these recent records; raw User-Agent strings are not stored. Browser-cached pages may not produce a server request. Response times measure server time until response headers; heartbeat requests are excluded. Collection starts after deployment; earlier traffic is unavailable.
