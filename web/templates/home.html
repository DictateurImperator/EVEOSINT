0.1.2 In development
Changes since 0.1.1

Sovereignty Intelligence

  • Added the CCP ESI current sovereignty collector using the current sovereignty systems endpoint.
  • Current sovereignty now stores the complete K-space snapshot returned by CCP, including explicit unclaimed systems.
  • Added a resumable, globally throttled DOTLAN sovereignty-history importer for conquerable nullsec systems.
  • Historical ownership is reconstructed across legacy SOV, IHub and SovHub eras.
  • Ownership changes are normalized as LOST + GAIN; no direct transfer is inferred from snapshot polling.

System History

  • Added a History view to solar-system profiles, based on the existing Player History interface.
  • System sovereignty history displays Alliance and historical root Coalition periods.
  • Unclaimed periods are displayed explicitly.
  • Each period calculates total kills in the system and its share of the system's recorded kill activity.
  • System pages now link directly between Map, Killboard and History views.

Entity History & Analysis

  • Added historical Coalition segmentation to Character, Corporation and Alliance histories.
  • Nested coalitions resolve to their effective root coalition, with INCLUDE / EXCLUDE history respected.
  • Coalition logos are now shown in affiliation history when available.
  • Affiliation timelines are interactive.
  • SuperIntel Evolution and Ship Analysis charts are now interactive.

Admin, Debug & Reliability

  • Added Admin Debug launch, stop, status and live-log controls for ESI and DOTLAN sovereignty collectors.
  • Added sovereignty SQL inspection, direct current ESI snapshot inspection and copy-to-clipboard controls for collector logs.
  • Added an independent systemd job/timer for current sovereignty collection.
  • Added cache / ETag / Expires handling, incomplete-snapshot guards and DOTLAN Retry-After protection.
  • Added offline sovereignty collector tests and migration handling for the new CCP sovereignty endpoint.
Base release: 0.1.1
