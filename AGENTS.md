# EVEOSINT development instructions

## Branch naming

All EVEOSINT development work MUST use a numbered branch of the form
`dev_X.Y.Z_NNN` (for example, `dev_0.1.3_060`). Fetch remote refs and check the
latest existing number before choosing the next available one. Do not publish
EVEOSINT work on an unnumbered branch, including `codex/...` branches.

Each new update MUST use a new numbered branch, even when continuing or fixing
the previous update. Never publish another update on the previously used number.
